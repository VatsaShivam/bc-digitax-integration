Setup and troubleshooting for the DigiTax UAE Invoice Connector for Business Central 28.

Set up the connector

  1. In Extension Management, enable Allow HttpClient Requests for the connector.
  2. Open DigiTax UAE Setup, set your sandbox API key, and run Test Connection. Enter the returned business ID and keep Allow Live Submission off during testing.
  3. Configure buyer, line, VAT, and payment mappings. On a posted sales invoice, run Validate DigiTax Invoice before sending.

Troubleshoot an invoice

  • Connection failed. Check outbound HTTP, the API key, and whether it belongs to the configured DigiTax business.
  • Validation failed. Check the posted document date, currency, and the mapping named in the error. DigiTax accepts issue dates within the past 30 days through today.
  • Processing. Use Refresh DigiTax Status to check validation, delivery, and reporting.
  • Unknown outcome or HTTP 409. Check the DigiTax dashboard for the original invoice before retrying. Use Reconcile DigiTax Invoice if you find its DigiTax invoice ID.

Get help

Contact your Business Central administrator or the provider who installed the connector. For DigiTax account access or a DigiTax-side processing issue, use the Support option in your DigiTax dashboard.

Include the connector version, the environment (sandbox or live), the exact error, and the steps to reproduce it. Remove API keys, customer details, and invoice contents from screenshots or public reports.
